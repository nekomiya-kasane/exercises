There're several possibilities for the appearance of unexpected results. For example, wrong usage, incompatible or unstable dependencies or environments, or internal coding bugs. To troubleshoot the problem, we should take the following steps

1. Reproduce the problem. In the same environment, using the same 3rd party packages, run the program again and do the same thing to reproduce it. If the problem is intermittent, try to identify any patterns that may help you narrow down the cause.
2. Check external factors. Review the manual and document to exclude external factors that may cause the problem.
3. Debug the code: If you are mostly sure that it's due to internal factors and have the source code. you can use a debugger tool to narrow down the problematic range and see where the program is deviating from the expected results.
4. Review & modify the code: Find the logic that cause the problem by understanding and testing the related codes. Try to correct it if you have find the causes.
5. Test the program: From low level to higher level. Do the unit test/module test/component test/whole test/blackbox test, try to construct some targeted cases and wide ranged case to cover as much as possible. Make sure that there are no degeneration and the problem is solved.
6. Recomfirm and commit: Rerun the modified program and use the initial input to make it output the correct output. Then commit and merge to the remote codes.
