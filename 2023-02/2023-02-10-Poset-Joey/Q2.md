## Q2

==Choose a countable infinite subset==

Since $A$ is infinite, we can find a countable infinite subset $X\subset A$ following such steps:

1. $A$ infinite → $A$ not empty, we take $x_0\in A$ and let $X=\{x_1\}$

2. $A-\{x_1\}$ infinite, we can take $x_2\in A-\{x_1\}$, and append it to $X$, now $X=\{x_1,x_2\}$

   ......

   Repeat

   ......

n.     $A-\{x_i:1\leq i\leq n\}$ infinite, we can take $x_{n+1}\in A-\{x_i:1\leq i\leq n\}$ and append it to $X$

......

Now $X=\{x_i:i\in\mathbb{N}\}\subset A$, as we can define $\varphi:X\to \mathbb{N},x_i\mapsto i$, $X$ is countable

==Define a partial order on $X$ and verify it is indeed a partial order== 

let $R=\{(x_i,x_j):x_i,x_j\in X,i\geqslant  j\}\subset X\times X$, then

1. $\forall i\in\mathbb{N},i\geq i\to\forall x_i\in X, (x_i,x_i)\in R$ (reflexivity)

2. $\forall i,j\in\mathbb{N}$, there is $i\geq j\wedge j\geq i\to i=j$, 

   hence $\forall x_i,x_j\in X$,  $(x_i,x_j),(x_j,x_i)\in R$ leads to $ i\geq j\wedge j\geq i\to i=j\to x_i=x_j$

3. $\forall i,j,k\in\mathbb{N}$ such that $i\geq j,j\geq k$, there's $i\geq k$,

   hence $\forall x_i,x_j,x_k\in X$, $(x_i,x_j),(x_j,x_k)\in R$ leads to $i\geq j,j\geq k\to i\geq k\to (x_i,x_k)\in R$

hence $R$ is a partial order, we can re-denote it as $\leq$. Thus we have an partially ordered subset $(X,\leq)$. 

==Extend it to uncountable infinite set $A$==

We'll extend this partial order on $X\subset A$ to $A$.

If $X=A$, then nothing to do;

If $X\neq A$, then let $S=A-X\neq \varnothing$. Define

$\hat R=R\cup \{(a,b)\in A\times A:(a\in X\wedge b\in A-X)\vee (a=b)\}$

Then easy to know $\hat R$ is still a partial order (prove omitted)

==Under this partial order, $A$ has no minimal element==

Take an arbitrary $a\in A$,

- if $a\in X$, then $\exist$ index $i\in \mathbb{N}$, s.t. $a=x_i$. Take $x_{i+1}\in X\subset A$, then by the definition $x_{i+1}\leq x_i$, $a$ is not a minimal element.
- if $a\in A-X$, then $\exist x_0\in X\subset A$, by the definition, $x_0\leq a$.

Hence $\forall a\in A$, $a$ is not a minimal element

 ==Summary== : Therefore, any infinite set $A$ has a partial order without minimal element.

## Q5

Since $A$ is a countable set, trivially, if $A$ is finite, then $|P(A)|=2^{|A|}<\infty$.  since $B\sub P(A)$, $|B|<|P(A)|<\infty$, which indicates $B$ is also countable (more precisely, finite).

We're going to consider when $A$ is countable infinite.

==$B$ can be written as a countable union of finite sets==

since $A$ is countable finite, there exists a injection $f:A\to \mathbb{N}$, 

for convenience, here we can use $f^{-1}$ to denote its 'inverse' defined on $f(A)$ instead of $\mathbb{N}$. that is $f^{-1}: f(A)\to A$, $f^{-1}(n)=a$ iff $f(a)=n$. $f^{-1}$ is well-defined since $f$ is injective.

let $S(n)=\{X\in P(A):\forall\ x\in X\subset A,f(x)\leq n\}$ 

note that for any fixed $n$, $\forall s\in S(n)$, $s\subset \{f^{-1}(i):1\leq i\leq n\}$, and $\forall Y\subset\{f^{-1}(i):1\leq i\leq n\}$, $\forall y\in Y$, there's $f(y)\leq n\ \to\ Y\in S(n)$

thus we know $S(n)=\{f^{-1}(i):1\leq i\leq n\}$, $|S(n)|=2^n$, that's to say, $S(n)$ is finite, and it can be enumerated as
$$
S(n)=\{s_{n,1}, s_{n,2},\cdots, s_{n,2^n}\}
$$
<u>Claim</u>: $B=\bigcup_{i=1}^{+\infty} S(i)$.

Proof: 

- for any $n\in \mathbb{N}, X\in S(n)$, by the definition, $X\subset \{f^{-1}(i):1\leq i\leq n\}$, the RHS is finite, hence $s$ is finite.

  Thus we have $\forall n\in\mathbb{N}, S(n)\subset B$, from which we can derive $\bigcup_{i=1}^{+\infty} S(i)\subset B$

- for any $X\in B$, $s$ is finite, hence $\{f(x):x\in X\}\subset\mathbb{N}$ is finite, it has a maximum, say $M$, thus $X\in S(M)\subset B$, from this we can derive $B\subset \bigcup_{i=1}^{+\infty}S(i)$.

Therefore $B=\bigcup_{i=1}^{+\infty} S(i)$ , $B$ is  a countable union of finite sets.

==Find a map from $B$ to $\mathbb{N}$==

Define $g(n,i)=2^n-2+i$, note that $g(n,2^n)=2^{n+1}-2<2^{n+1}-1=g(n+1,1)$, fix $n$, $g$ is increasing w.r.t $i$, hence on
$$
I=\{(n,i):n\in\mathbb{N},1\leq i\leq 2^n\}
$$
$g$ is  an injection.

By the conclusion above, $\forall x\in B$, there is at least one $S(n)$ (for some $n$) containing $x$. 

let $J(x)=\{(n,i):x=s_{n,i}\in S(n),1\leq i\leq 2^n\}\subset I$.

then $\forall x\in B,(g\circ J)(x)\subset \mathbb{N}$, by the minimum principle, it must contain a minimal, we can define a map $h:B\to \mathbb{N}$
$$
\forall x\in B,h(x)=\min (g\circ J)(x)
$$
==The defined map should be injective==

then $h$ must be injective. We're prove this by contradiction.

suppose $h$ is not injective, then $\exist x,y\in B,x\neq y$, but $h(x)=h(y)$. 

since $g$ is injective on $I$, we have $J(x)\cap J(y)\neq \varnothing$. Take $(n,i)\in J(x)\cap J(y)$, we have

$x=s_{n,i}=y$, contradictory. Therefore $h$ is an injective from $B$ to $\mathbb{N}$, $B$ is countable infinite.

**Remark: ** if infinity is define by a bijection to $\mathbb{N}$, the proof should be easily fixed noting that there exists a bijection between $\mathbb{N}$ and any of its infinite subset.
