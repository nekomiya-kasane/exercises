Consider the following scalar discrete-time control system

x(k+1)=2x(k)+u(k)x(k+1)=2x(k)+u(k)
where x∈Rx∈R, u∈Ru∈R and x(0)=−2x(0)=−2. Let N>1N>1 be some integer.

  1. Consider the following cost function

    J=∑k=0Nu(k)2J=∑k=0Nu(k)2
    Find the optimal control law and the minimal cost.

  2. Consider the following cost function

    J=∑k=0Nx(k)2J=∑k=0Nx(k)2
    Find the optimal control law and the minimal cost.

  3. Consider the optimal control problem of 2.2. with the constraint |u(k)|≤0.5|u(k)|≤0.5. Find the optimal control law.

I will give you some hints:

(a)(a) Your cost does not depend on the state xx. You only have uu in it, which is your control input (you have total control about what will happen with u(k)u(k)). Do you see how the cost can be minimized if we do not care about the state xx?

(b)(b) The cost now depends on the state xx. As long as the state is not zero we will accumulate additional cost. Can you think of a control input u(k=0)u(k=0) such that x(k=1)=0x(k=1)=0? This means that we are driving the system directly to the origin. This type of control is called dead beat control and is not possible for linear continuous time-invariant systems but possible for linear time-invariant discrete systems. Use x(k+1)=2x(k)+u(k)x(k+1)=2x(k)+u(k) and the initial condition. Remember that this problem does not give us any constraints on the inputs u(k)u(k). If the system is in the origin after one step what will u(k)u(k) be for k≥1k≥1?

For (c)(c) try to understand what the system does for u(k)=0.5u(k)=0.5 and u(k)=−0.5u(k)=−0.5. We only consider the state x(k)x(k) in our cost function. How could you minimize this cost given the constraint |u(k)|≤0.5|u(k)|≤0.5? Also note that the cost function is only a finite sum.
