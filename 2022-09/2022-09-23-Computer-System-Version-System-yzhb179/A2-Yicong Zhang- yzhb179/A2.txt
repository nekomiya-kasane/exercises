Q. Discuss the pros and cons of deleting all versions if a file is deleted in the mount directory
Ans:
pros:
1.This is a memory saving.

cons:
1.Deleting is also a kind of modification, it should be consistent with the changes.
2.Prevents users from deleting files by mistake
