经过观察，可以发现3个异常数据点，即上图中产生纵线的数据点，我们使用插入平均值方法清除了这些数据点，并将数据线性归一化到$[-1,1]$区间。

```matlab
for i=1:len
     vi(i)= Hn(i)-mean1;    	% 样本数据偏差
     std1=std(Hn);              % 标准差
     if abs(vi(i))>3*std1       % 3倍标准差阈值   
        Hn(i)=mean1;        	% 均值替代异常值
        count=i;
     end
end

for j=1:len     
	c(j)=lower+(upper-lower)*(Hn(j)-Cmin)/(Cmax-Cmin);  %归一化 
end
```

采用**6月1~3日**数据作为输入， **6月4~6日**数据作为输出，共建立4320组输入输出单元，在它们当中采用1440组作为训练数据，1440组作为验证数据。
