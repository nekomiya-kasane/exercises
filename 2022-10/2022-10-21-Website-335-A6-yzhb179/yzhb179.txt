Answer: partial


We already know that the password for `jbon007` is `jbon007passwd` , and we need to know the Hash Algorithm and the mapping between password and its hash string.

Let’s disassemble `GameAcademy.dll` with `ILSpy`, luckily, a `pdb` file is distributed together with the server.

the first screenshot shows the entrance of authentication, note there’s a line saying

string passwordHash = GetMD5Hash(username, password);

keyword `MD5` suggests that the encyption method is MD5, and it makes uses of both username and password.

let’s dive into `GetMD5Hash` method, which is shown in the second screenshot, then we could find

sb.AppendFormat((j == input.Length - 1) ? "{0}" : "{0}:", s);

hence it can be derived that the MD5 Hash is computed from the string of form `username:password`. By transversing Oxford Dictionary, and comparing MD5 Hashes, the answer is found. see report for details.
