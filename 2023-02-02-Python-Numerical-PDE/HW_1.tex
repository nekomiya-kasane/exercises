    \textbf{Reason:}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  for \(n < 8\), \(\Delta x\) is not so small, hence the floating point
  won't cause large truncating errors.
\item
  as the step size \(\Delta x\) descreases, the upper bound of
  calculated derivatives are also descresing. And the approximation of
  leftmost and rightmost point (switched forward and backward finite
  differences) also becomes more precise.
\item
  the norms are equivalent and \(L_\infty\) norm doesn't concern with
  array lengths.
\end{enumerate}

    Expand \(f(x)\) around \(x\), we have

\[f(x-\Delta x) = f(x) - \Delta x f'(x) +\Delta x^2\dfrac{f''(\zeta_1)}{2!} \]

\[f(x-\Delta x) = f(x) - \Delta x f'(x) +\Delta x^2\dfrac{f''(x)}{2!} -\Delta x^3 \dfrac{f'''(x)}{3!}+\Delta x^4 \dfrac{f''''(\eta_1)}{4!}\]

\[f(x-\Delta x) = f(x) - \Delta x f'(x) +\Delta x^2\dfrac{f''(x)}{2!} -\Delta x^3 \dfrac{f'''(x)}{3!}+\Delta x^4 \dfrac{f''''(x)}{4!} - \Delta x^5 \dfrac{f^{(5)}(x)}{5!} + \Delta x^6 \dfrac{f''''(\mu_1)}{6!}\]

together with

\[f(x-2\Delta x) = f(x) - 2\Delta x f'(x) +4\Delta x^2\dfrac{f''(\zeta_2)}{2!} \]

\[f(x-2\Delta x) = f(x) - 2\Delta x f'(x) +4\Delta x^2\dfrac{f''(x)}{2!} -8\Delta x^3 \dfrac{f'''(x)}{3!}+16\Delta x^4 \dfrac{f''''(\eta_2)}{4!}\]

\[f(x-2\Delta x) = f(x) - 2\Delta x f'(x) +4\Delta x^2\dfrac{f''(x)}{2!} -8\Delta x^3 \dfrac{f'''(x)}{3!}+16\Delta x^4 \dfrac{f''''(x)}{4!} - 32\Delta x^5 \dfrac{f^{(5)}(x)}{5!} + 64\Delta x^6 \dfrac{f''''(\mu_1)}{6!}\]

and

\[f(x-3\Delta x) = f(x) - 3\Delta x f'(x) +3^2\Delta x^2\dfrac{f''(\zeta_3)}{2!} \]

\[f(x-3\Delta x) = f(x) - 3\Delta x f'(x) +3^2\Delta x^2\dfrac{f''(x)}{2!} -3^3\Delta x^3 \dfrac{f'''(x)}{3!}+3^4\Delta x^4 \dfrac{f''''(\eta_3)}{4!}\]

\[f(x-3\Delta x) = f(x) - 3\Delta x f'(x) +3^2\Delta x^2\dfrac{f''(x)}{2!} -3^3\Delta x^3 \dfrac{f'''(x)}{3!}+3^4\Delta x^4 \dfrac{f''''(x)}{4!} - 3^5\Delta x^5 \dfrac{f^{(5)}(x)}{5!} + 3^6\Delta x^6 \dfrac{f''''(\mu_3)}{6!}\]

where \(\zeta_1, \zeta_2 \in (x-\Delta x, x)\),
\(\eta_1, \eta_2 \in (x - 2\Delta x, x)\)

\[f'(x)\approx\dfrac{3 f(x)- 4 f(x-\Delta x) + f(x - 2\Delta)}{2\Delta x}\]

\section{3}\label{section}}

Solving the following PDEs showing the relevant steps and plot a few
time snapshots of the solution.

    \textbf{(a)} {[}15{]} \(u_t = \kappa u_{xx}\) with
\(x \in \Omega = (0, L)\), the boundary conditions \(u(0, t)_x = 0\) and
\(u_x(L, t) = 0\), and the initial condition
\(u(x, 0) = 2 - \cos\left(\frac{\pi x}{L} \right) + 3 \cos\left(\frac{3 \pi x}{L} \right)\).
When plotting the solution pick a value for \(L\) and play with values
of \(\kappa\). Make sure your solution makes sense as
\(t \rightarrow \infty\).

    We'll discrete the space and solve along the time. i.e.~

after the discretization, we got an ODE equation about time
\(u_t=f(t,u)\):

\[u_t=\kappa \dfrac{u_{i+1}-2u_i+u_{i-1}}{h^2}\]

the we can apply numerical methods to solve it, here we adopt the 4-th
order Runge-Kutta Method, for an ODE \(x(t) = f(x,t)\):

\begin{verbatim}
k1 = h * f(x, t)
k2 = h * f(x + k1/2, t + h/2)
k3 = h * f(x + k2/2, t + h/2)
k4 = h * f(x + k3, t + h)
x(t+h) = x(t) + (k1 + 2*k2 + 2*k3 + k4)/6
\end{verbatim}
